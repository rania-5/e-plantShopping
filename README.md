# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux. Users can browse a variety of houseplants grouped by category, add them to a shopping cart, update quantities, and see the total cost of their order.

## Features
- Landing page with company name and a "Get Started" button
- Product listing page with plants grouped by category
- Shopping cart with quantity controls and total amount
- Built with React, Redux Toolkit, and Vite
